# Sources — Rigg / Brian's car reference: Toyota Celica (T160)

- **1986 Toyota Celica GT-S Liftback** — fourth generation, T160 series (1986–1989)
- Trim note: this is the **GT-S**, the top trim of the same T160 liftback body. - Interior: black leather bucket seats (as photographed)
- VIN (from listing page): JT2ST65L9G7002636 — ST65 = T160 GT-S liftback
