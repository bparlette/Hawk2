## Caveats for the modeller

- **COLOUR: this set is for SHAPE / PANELS / GLASS / PROPORTIONS reference only. Canon paint for Jimmy's van is SILVER — apply the canon silver on top of this shape.** (The reference van is white-over-silver two-tone; its silver lower band is a useful tone guide, but the game van is silver overall.)
- **Wheels are NOT factory:** the seller lists 15-inch Eagle alloy wheels as a modification. Use the photos for wheel-arch shape, tire size and stance — not for rim design. Fit a period factory Astro wheel/cover design in the model.
- **Window rain guards** (smoked visors over the front windows) are also a seller-listed add-on, not factory.
- This is a Chevrolet Astro, **not** the GMC Safari twin. Badging in the photos (bowtie grille, CHEVROLET tailgate script, ASTRO badges) is genuine Chevy.
