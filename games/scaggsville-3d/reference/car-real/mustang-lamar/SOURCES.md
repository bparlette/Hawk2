# Lamar's car — real reference photos: 1987 Ford Mustang GT Hatchback

## Purpose — SHAPE ONLY
This set is purely shape / panels / glass / wheels reference for modelling.
**In the game (Scaggsville), Lamar's Mustang is BURNT** — dark smoke + gold-orange
ember glow, no flame tongues. Do NOT copy this car's clean grey paint, blue
stripe, or condition. Copy only the Fox-body hatchback silhouette, panel
breaks, glasshouse, lights, GT ground effects and spoiler.

## Car identity (as sourced)
- **Year / model / trim:** 1987 Ford Mustang GT Hatchback (Fox body, 1987–1993
  "aero" facelift generation — flush composite headlights, not sealed beams)
- **Engine / gearbox:** 5.0L V8, 5-speed manual
- **Colour:** Gray (grey metallic) with blue side stripe; grey cloth interior
- **Mileage:** ~55,000 miles
- **VIN (as listed):** 1FABP42E0HF180695 (P42 = Mustang GT hatchback)
- **Details from listing:** sunroof, A/C, power windows/mirrors/steering,
  factory radio/cassette with equalizer, original bill of sale/title/window
  sticker included. Sitting on period-correct 16in basket-weave rims with
  Ford-script centre caps (seller believes dealer option — so the WHEELS in
  these photos are NOT the factory GT turbine wheels; use them for tyre/arch
  proportions, not as factory wheel canon).
- **Asking price at listing:** $29,500
