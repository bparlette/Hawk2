# Kosack's Car — Real Reference Photos: 1996 Chevrolet Cavalier

## Car identity (as sourced)
- **Year / model:** 1996 Chevrolet Cavalier
- **Body:** 2-door coupe, base trim (unpainted dark-gray bumpers, black side molding, steel wheels with full wheel covers)
- **Generation:** Third generation (1995–2002), pre-facelift 1995–1999 body — correct 1996 shape: teardrop headlights, slatted lower grille, oval taillights, "CAVALIER" / "CHEVROLET" trunk badging
- **Colour of the photographed car:** Sandrift Metallic (beige/tan)
- **Location / date photographed:** Rogers, Ohio, 7 June 2024
- **Photographer:** MercurySable99 (own work, Wikimedia Commons)
- **Mileage / VIN:** not applicable — Commons photo shoot, not a sale listing

## Colour caveat
**This set is for SHAPE reference only — panels, glass, proportions, wheels, lights, badging. Canon paint for Kosack's car is RED; apply the red paint on top of this shape. The same shape also covers the black Cavalier variant.**
